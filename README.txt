GitHub Pages:
1. Neues öffentliches Repository erstellen, z. B. tina-stef-rezepte
2. Alle 5 Dateien aus diesem Ordner direkt in die oberste Ebene des Repositories hochladen.
3. GitHub: Settings -> Pages
4. Source: Deploy from a branch
5. Branch: main / (root)
6. Save
7. Nach kurzer Zeit erscheint die GitHub-Pages-Adresse, typischerweise:
   https://DEIN-BENUTZERNAME.github.io/tina-stef-rezepte/

Samsung:
1. Alten Homescreen-Link löschen.
2. Die GitHub-Pages-Adresse in Chrome öffnen.
3. Chrome-Menü -> Zum Startbildschirm hinzufügen / App installieren.
4. Danach sollte das T&S-Icon erscheinen.

Hinweis:
Die eigentliche Rezept-App und Datenbank bleiben weiterhin bei Google Apps Script.
Der GitHub-Pages-Wrapper stellt nur Name, Icon und App-Rahmen bereit.
